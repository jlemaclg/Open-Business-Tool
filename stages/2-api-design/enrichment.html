¿No encuentras tu campo en ISO 20022?

Si el campo es específico de tu geografía — por ejemplo RFC, CLABE para México · DNI, RUC para Perú · NIT, CC para Colombia — márcalo como campo local:

x-gov-note: "Local field — specific to [GEO]"
x-gov-geography: "[MX|PE|CO|ES|AR]"

Estos campos van a /geography-overlays/ en el repositorio canónico y no bloquean la aprobación del schema en el proceso de gobernanza.
